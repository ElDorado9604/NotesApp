# NotesApp

A simple client-side notes app (static HTML/CSS/JS) for creating and viewing notes.

## Features
- Add and view notes in the browser
- Light and dark themes (`dark-mode.css`)
- Single-file frontend: `index.html`, `styles.css`, `script.js`

## Files
- `index.html` — main page
- `styles.css` — default styles
- `dark-mode.css` — dark theme stylesheet
- `script.js` — app logic

## Usage
1. Open `index.html` in your browser (double-click or drag into the browser).

Or serve locally (recommended) to avoid CORS issues with some browsers:

```bash
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

## Development
- Edit `script.js` to change behavior
- Styles in `styles.css` and `dark-mode.css`
